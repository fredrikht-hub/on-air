# ON AIR — Typing Tycoon

An idle game where typing real English is the engine. Shout the news in a town square,
grow into a newspaper and a radio station — and get faster at typing along the way.

**Play:** https://fredrikht-hub.github.io/on-air/

## Run locally
```
npm install
npm run dev
```

See `DESIGN.md` for the game design.
